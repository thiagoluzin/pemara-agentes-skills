# Observação após ComfyUI

Depois de uma execução já autorizada, guarde os tempos do job, configuração técnica, resolução, frames e fases com dados no canal MCP autorizado. Colete RAM e VRAM apenas quando o runtime oferecer métricas admissíveis. Identifique se os valores são máximos observados ou amostras pontuais.

Compare com execução equivalente, mesma qualidade e mesmo motor. Separe transferências de pesos, espera e amostragem. Uma hipótese semântica de gargalo pode ser avaliada pelo Gemini Decision 1 no escopo autorizado. A leitura de métricas não inicia um novo render, monitor ou reinício.
