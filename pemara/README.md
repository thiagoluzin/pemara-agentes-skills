# Coleção PEMARA

A coleção reúne 87 skills, 49 perfis de compatibilidade, oito perfis especializados e um coordenador. Abra o [mapa por objetivo](skills/pemara-messenger-turbo/references/routing-map.md) ou selecione diretamente uma pasta em `skills/`. As referências relativas partem do documento que as cita. Conserve a estrutura se quiser usar a coleção inteira.

Em um cliente com suporte ao padrão de skills, indique a pasta `skills/` conforme a configuração desse cliente. Os perfis apontam para o conteúdo canônico. Execute `python skills/pemara-messenger-turbo/scripts/audit_turbo_registry.py` a partir desta pasta para validar os vínculos. As entradas documentam ferramentas opcionais, que dependem da instalação e autorização do operador.
