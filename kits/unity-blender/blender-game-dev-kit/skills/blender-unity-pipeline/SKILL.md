# blender-unity-pipeline

Use metros como contrato quando o projeto assim definir; confira dimensões importadas com um objeto conhecido. Preserve origem, hierarquia, material slots e nomes; FBX não transporta qualquer shader ou constraint. Troque candidato com novo nome e revise escala, normais, colisão e pivôs no Unity. Só após verificação atualize referência do prefab, preservando .meta quando for atualização do mesmo asset. Documente separadamente validação técnica e aprovação visual.

## Entrega

Informe o problema, a alteração ou diagnóstico, a evidência executada e os limites observados. Respeite a versão e as decisões do projeto. Esta especialidade não inicia outros agentes automaticamente.
