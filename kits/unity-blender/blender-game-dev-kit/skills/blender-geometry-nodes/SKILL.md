# blender-geometry-nodes

Exponha parâmetros úteis e limites; fixe seeds quando resultado precisa ser reproduzível. Verifique instâncias versus geometria realizada antes de exportar. Conte geometria avaliada e custo ao variar densidade. Não realize milhões de instâncias apenas para contagem se outra medida basta. Preserve node group fonte e gere exportação separada quando precisar aplicar o resultado.
