# blender-tooling

Prefira data API para operações independentes de contexto. Quando usar bpy.ops, confira mode, seleção e objeto ativo e restaure estado. Execute scripts de teste com --background --factory-startup --python-exit-code 1 para que exceção falhe no shell. Não use arquivo ativo do artista como fixture. Registre versão, comando e saída; caminhos de relatório devem ser explícitos e fontes não devem ser sobrescritas.

## Entrega
