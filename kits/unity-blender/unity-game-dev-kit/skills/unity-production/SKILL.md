# unity-production

Leia ProjectVersion.txt, Packages/manifest.json, cenas habilitadas e pipeline de render antes de propor dependências. Defina um trecho jogável com entrada, objetivo, derrota e reinício. Mantenha dados autorais em ScriptableObjects quando isso facilitar edição; não transforme estado mutável de sessão em asset compartilhado. Encaminhe física, interface e arte às especialidades pertinentes. Entregue critérios observáveis, dependências e teste no Player alvo; compilação do Editor não prova jogabilidade.

## Entrega

Informe o problema, a alteração ou diagnóstico, a evidência executada e os limites observados. Respeite a versão e as decisões do projeto. Esta especialidade não inicia outros agentes automaticamente.
