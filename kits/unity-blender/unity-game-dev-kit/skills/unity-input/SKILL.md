# unity-input

Inspecione Active Input Handling e pacotes antes de usar Input System; projetos com XInput ou Input Manager não autorizam migração implícita. Separe ações de UI e gameplay, aplique deadzone radial e normalize diagonais. Cancele intenção ao perder foco ou abrir pausa. Verifique desconexão, reconexão, jogador correto e gatilhos independentes. Teste matemática sem hardware e reporte separadamente o teste com controle físico. Não afirme suporte a aparelho ausente.

## Entrega

Informe o problema, a alteração ou diagnóstico, a evidência executada e os limites observados. Respeite a versão e as decisões do projeto. Esta especialidade não inicia outros agentes automaticamente.
