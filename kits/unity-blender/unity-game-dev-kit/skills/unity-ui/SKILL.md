# unity-ui

Identifique uGUI ou UI Toolkit existente e preserve a escolha. Teste foco inicial, retorno ao menu, gamepad e mouse alternados, safe area e textos longos. Separe estado do menu e estado da corrida. Atualize HUD quando dados mudarem, evitando alocação por frame sem medida. Verifique Canvas Scaler e resolução mínima no Player. Pausa deve bloquear gameplay e manter UI navegável.
