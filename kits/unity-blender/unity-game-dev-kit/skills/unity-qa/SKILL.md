# unity-qa

Use EditMode para lógica pura e integridade de assets; PlayMode para física e ciclo de vida; Player para empacotamento e dispositivos. Registre engine, plataforma, cena, seed quando disponível e comando. Exercite menu, corrida, pausa, derrota, vitória e reinício sem reiniciar processo. Faça testes falharem com código de saída não zero. Não confunda smoke test com aprovação visual ou teste físico de gamepad. Utilize o auditor instalado da especialidade tooling para inventário inicial.

## Entrega

Informe o problema, a alteração ou diagnóstico, a evidência executada e os limites observados. Respeite a versão e as decisões do projeto. Esta especialidade não inicia outros agentes automaticamente.
