# unity-release

Confirme versão exata, plataforma instalada e licença local. Use BuildPipeline.BuildPlayer e confira BuildReport.summary.result; falha precisa encerrar batch com erro. Informe -buildTarget junto ao método de build. Não abra duas instâncias no mesmo projeto. Execute o Player distribuído em diretório limpo, teste save e primeira execução. Audite licenças e arquivos incluídos. Preserve build anterior e distinga compilação, instalador, assinatura e aprovação humana.

## Entrega

Informe o problema, a alteração ou diagnóstico, a evidência executada e os limites observados. Respeite a versão e as decisões do projeto. Esta especialidade não inicia outros agentes automaticamente.
