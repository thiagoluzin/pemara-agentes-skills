# Proveniência

Este pacote foi escrito para generalizar aprendizados de uma auditoria de ferramentas de produção de jogos. As instruções foram reescritas, os papéis consolidados e os exemplos executáveis implementados especificamente para esta distribuição.

Nenhum asset, personagem, trilha, código de gameplay, master de arte, configuração privada ou histórico do jogo de origem foi incluído. Nenhuma skill de plugin comercial ou coleção de terceiros foi redistribuída. Nomes das especialidades anteriores aparecem apenas para explicar a consolidação.

Phaser e Playwright são dependências de desenvolvimento obtidas pelos seus próprios pacotes, com licenças e avisos respectivos. Não são incorporados ao conteúdo licenciado deste kit. Marcas citadas pertencem aos seus titulares. Não há afiliação ou endosso implícito de Phaser Studio, OpenAI ou outros fornecedores.

Referências oficiais estão vinculadas nos documentos; consultar uma referência não transfere sua licença ao kit. A licença MIT deste repositório se aplica ao código e texto novos aqui contidos.
