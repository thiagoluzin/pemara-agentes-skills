# HyperFrames

Origem dos pacotes: [HyperFrames](https://github.com/heygen-com/hyperframes). Os arquivos distribuídos foram comparados um a um com os objetos Git de origem. Consulte a licença e os avisos incluídos.

Nesta distribuição, o módulo de telemetria de media-use usa a variável opcional MEDIA_USE_TELEMETRY_KEY. Sem configuração explícita, a coleta fica desligada. A edição aplica-se somente a esta cópia.
