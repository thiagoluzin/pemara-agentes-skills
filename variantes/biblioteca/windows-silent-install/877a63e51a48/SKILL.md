# windows-silent-install

Preparar instalação não interativa somente de pacotes solicitados. Confirmar editor e identidade do pacote no catálogo autorizado, conferir assinatura quando disponível e selecionar o menor escopo de privilégio compatível. Documentar código de saída, versão instalada e possibilidade de desinstalação.
