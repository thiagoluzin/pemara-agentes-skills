# Variantes de agentes e skills

Cada diretório de cliente ou projeto contém entradas com nome e descrição próprios. Elas apontam para uma versão em `biblioteca/`; preserve essa posição relativa ao copiar os arquivos. Corpos iguais compartilham uma versão, e variantes com decisões diferentes continuam endereçáveis. `ritmos-final` reúne os perfis do projeto final. `ritmos-colecao` conserva a outra coleção do jogo. `loja-kit` e `ritmos-kit` incluem perfis e extensões associados ao kit de seus projetos.

As definições derivadas do **Antigravity Kit, de vudovn**, conservam o [aviso MIT](LICENSE-AG-KIT.txt). A edição pública transforma caminhos de exemplo e remove blocos de instruções universais de versões históricas. As rotinas de manutenção do Windows e os auxiliares de teste de extensão são descrições portáteis de escopo. Algumas receitas históricas mencionam ferramentas ou recursos da stack de origem; confirme sua disponibilidade no projeto de destino.

As variantes de revisão de ambientes Python e a receita de plataformas 16-bit receberam versões editoriais portáteis. As referências detalhadas de design móvel usam o commit indicado do kit de origem.
