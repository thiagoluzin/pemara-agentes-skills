# Perfis de clientes

O diretório Codex contém sete perfis de agentes e cinco skills. Para instalação pessoal, mantenha `agents/` e `skills/` lado a lado na pasta de configuração do Codex. Os quatro perfis de música requerem a skill de gênero homônima da coleção PEMARA. As três especialidades de Krita requerem o plugin MCP correspondente. A skill de inspeção de vídeo usa o CLI de uma instalação compatível do Maestro.

O diretório OpenCode contém uma seção `agent` com doze perfis, nove prompts, sete skills e o contrato de execução. Para ativá-los, mescle a seção de `agentes.json` à configuração escolhida e disponha `prompts/`, `skills/` e `instructions/` ao lado dessa configuração. Revise os campos `permission` de acordo com o uso autorizado no seu projeto. As ferramentas específicas do harness dependem de uma instalação compatível.
