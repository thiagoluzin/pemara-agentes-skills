# Mira

Mira é uma ideia original do Sandeco. Esta edição reúne 26 skills da instalação Mira Turbo, com ajustes de portabilidade e exemplos locais generalizados. As skills usam o runtime e os templates do Mira. Consulte a instalação do projeto original para utilizá-los.
